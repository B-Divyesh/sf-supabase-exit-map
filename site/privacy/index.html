Privacy for Supabase Exit Map

This notice explains how the CLI and website handle data.

The CLI

The CLI reads files beneath the directory you select. It has no analytics or telemetry and does not make network requests. Reports stay in your terminal or in the output file you choose. Do not publish a report before reviewing its file paths and evidence.

The website

This static website has no analytics, advertising pixels, third-party fonts, or tracking scripts. Its service worker caches public site files on your device so the guide can work offline.

Local browser storage

The site stores a theme choice in your browser. Restored licenses and saved Planning Room plans also stay in browser storage. Your imported report and planning choices are not uploaded. You can remove them by clearing site data in your browser.

Purchase and license verification

Checkout registration is pending, so this site cannot take a purchase now. Sociobot and Dodo will be the merchant of record when checkout is available. This site sends a restored license token to api.sociobot.in for verification. The verifier may receive ordinary request metadata such as IP address and user agent. We do not send your project report with that request.

Contact and changes

Use the repository’s public issue tracker for privacy requests. Do not post credentials or private project data. Material changes will be dated here.
